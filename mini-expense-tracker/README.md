Mini Expense Tracker
📌 About
A simple Python project to record expenses, manage a ₹5,000 budget, categorize spending, and save expense history using JSON.
🐍 Concepts Used
Data Types: int, float, str, bool, list, tuple, set, dict
Operators: Arithmetic, comparison, assignment
Control Flow: if, elif, else, while, for
Functions: save_expense(), load_expenses(), get_total(), to_dict(), summary()
OOP: Class, object, __init__(), methods
File Handling: Read/write/append files
Modules: os, json, datetime
Exception Handling: try, except
String Operations: .upper(), .lower(), .strip(), .title(), f-strings
✨ Features
Add and categorize expenses
Track total and remaining budget
Category-wise budget limits
Save and load expense history
Display spending summary
Handle invalid inputs
▶️ Run
Open expense_tracker.py in VS Code and run:
python expense_tracker.py
